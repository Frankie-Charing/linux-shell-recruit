# Task 02 Answer

## 1. 为什么 `./tools/recruit-info` 可以运行，而直接输入 `recruit-info` 找不到它？

`./tools/recruit-info` 是「相对路径 + 文件名」，Shell 会直接按照这个明确路径去执行该文件，所以只要该文件有执行权限（`x`）就能运行。而直接输入 `recruit-info` 时，Shell 会把它当成一条命令，按照 `PATH` 环境变量列出的目录从左到右逐个查找同名的可执行文件。`tools/` 目录默认不在 `PATH` 里，所以找不到，于是报 `command not found`。

## 2. 当我们输入 `ls` 时，Shell 是如何找到对应程序的？

Shell 收到 `ls` 后，会在 `PATH`（一个用冒号分隔的目录列表，例如 `/usr/local/bin:/usr/bin:/bin`）中从左到右查找第一个名为 `ls` 且具有执行权限的文件，找到后执行它。可以用 `command -v ls` 或 `which ls` 查看它实际指向的位置。

## 3. 让当前 Shell 会话中直接运行 `recruit-info`

```bash
export PATH="$PWD/tools:$PATH"
recruit-info
```

这只是在当前会话临时生效，不移动文件、不用 `sudo`、也不修改 `.bashrc` 等永久配置文件。
