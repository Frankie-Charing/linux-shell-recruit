# Task 08 Answer

## 为什么 Shell 中 `$var` 和 `"$var"` 有时会产生不同的结果？

不加引号的 `$var` 会被 Shell 做「单词拆分」（word splitting）和「路径名展开」（glob）。如果变量值里含有空格、制表符或换行，它会被拆成多个参数；如果值里含有 `*`、`?` 等通配符，还可能被展开成匹配到的文件名。

而 `"$var"` 会把变量的值当作一个整体参数，不做拆分、不做通配符展开。

所以当变量的值包含空格（例如文件名 `My Report.txt`）或通配符时，两者结果不同：`$var` 可能被拆开而把「一个文件名」变成「多个参数」导致命令出错，`"$var"` 才是安全写法。
